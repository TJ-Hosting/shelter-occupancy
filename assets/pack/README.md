# shelter-occupancy: pre-generated image pack (2026-10-15)

Made by agent=claude (Cowork, cloud session linked to BANE-VICTUS-TOP) for TJ, before the build dispatch `shelter-01` (brief v2, `dispatches/BRIEF-v2-shelter-01-2026-10-15.md`).

- **What it is:** 25 images, generated through the laptop's image-gen skill with no per-image spend: Grok Imagine 25, Gemini 0.
- **Why no Codex:** it was left out because another run on the laptop was using Codex image generation (the skill's rule: never two Codex jobs at once).
- **Ledger:** every file has a line in `LEDGER.jsonl` (provider, full prompt, dimensions, date). `CONTACT.jpg` is an overview.
- **Shared style:** one style sentence in every prompt: warm painterly illustration, sunset amber, coral and rose fading to dusky violet and navy, Toronto, no people, no text.

**Use rules.** These images are atmosphere, never data. Don't present them as photographs: the skylines are stylised, and the towers other than the CN Tower aren't architecturally accurate. Every image needs alt text or a decorative mark.

**Resolution.** 1280×720 (16:9), 720×1280 (9:16), 1248×832 (3:2) and 1024×1024 (1:1). That is fine behind overlays and in cards, but soft as a full-bleed retina hero. Convert to AVIF/WebP at responsive sizes and never upscale silently; regenerate a hero at higher resolution if it needs one.
